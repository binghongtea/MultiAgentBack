# Java + Agent + 前端全栈：作品集选题
调研日期：2026-10-16。中国大陆跨城市；用户尚未提供经验年限和目标城市。

## 结论
以 Java 业务岗位适配为主，优先“供应链/订单管理 + 运营 Agent”；以复用现有 RAG、尽快形成演示为主，优先“智能客服 + 售后工单”。随后考虑企业审批工作流；工业数据问答作为行业定向补充。此排序是作品集适配判断，并非全国岗位量排名。

## 取证口径
本附录精选 10 条岗位记录：6 条 BOSS 公开列表摘要，4 条企业官网详细 JD；不是 10 条完整 BOSS JD。官网部分在本轮曾成功读取，末次复查超时。所有岗位发布时间未知，不能确认近 90 天发布或持续在招。无可比历史数据，不报告岗位增长率或市场占比。原始字段见同名 JSON。

## 1. 供应链/订单管理 + 运营 Agent
证据：硕磐智能 Java 供应链 18–35K、3–5年本科；晖联科技采购/供应链 Java 15–25K、3–5年本科；阿里云供应链/Agent 应用 20–40K、1–3年本科。[公开列表](https://m.zhipin.com/zhaopin/2ba655b74d90b2f603F-3tS1GQ~~/)
项目设计：供应商、采购单、入库、库存预占、出库、对账。Agent 查询延期订单、调用库存与供应商工具、生成补货申请草稿，经人工确认进入审批。前端提供采购工作台、库存表格、异常看板和执行轨迹。
可讲深的问题：状态机、库存并发、事务、重复消息、接口幂等、工具权限、业务失败与模型失败分开处理。缩小范围，只做采购到入库闭环即可。

## 2. 智能客服 + 售后工单 SaaS
证据：阿里国际客户体验高级 Java 开发 18–30K·16薪、3–5年硕士，职责含大模型智能客服。[公开列表](https://www.zhipin.com/zhaopin/6a1df3ae3ae0bccc1nJz39y6Eg~~/)
项目设计：知识文档、客户与订单、工单分派与流转、人工接管。Agent 检索有引用的答案、查询订单与物流、创建售后草稿；前端展示客服工作台、知识管理、工单、质检与执行轨迹。
适合复用当前 Python RAG 的文档与问答积累；Java 承接业务 API 与权限，前端独立交付。权限检索、无依据拒答、工具失败恢复、响应延迟和单次成本必须可测。

## 3. 企业审批工作流 + 文档助手
证据：华腾建信中级 Java 后端 10–12K、3–5年本科，明确工作流引擎开发。[公开列表](https://www.zhipin.com/zhaopin/34974d202ece69191HN73ty4Fw~~/) 润宇官网全栈岗位同时覆盖前后端交付、AI/知识库/工作流集成。[官网](https://www.runyuchina.com/about/jobs/)
项目设计：采购申请或费用报销二选一，表单、审批、退回、撤回、通知、审计；Agent 抽取附件字段、解释制度、补齐申请草稿。审批权限和最终状态由业务规则控制。
这是依据相邻岗位要求组合的作品集方案，不宣称上述公司正在招这个项目的完整同款。前端重点是动态表单、流程可视化、待办与审计时间线。

## 4. 工业运维数据平台 + 数据查询 Agent
证据：涛思数据官网 Agent 与方案部署岗位涉及时序数据、数据库/API工具、SQL、监控恢复与工程交付；部分要求 Python 及另一门语言，并非 Java 单语言岗位。[官网](https://www.taosdata.com/careers)
项目设计：模拟设备时序数据、告警规则、运维工单、趋势看板；Agent 查询异常、关联日志与手册、生成带数据来源的排查建议。限定只读 SQL、查询范围与超时。
行业门槛和数据准备成本更高，适合目标为工业软件、制造业数字化或数据产品时做补充。

## 对全栈定位的直接证据
磐石云“Java工程师（AI Agent全栈方向）”10–15K，苏州，3–5年本科。[BOSS](https://www.zhipin.com/zhaopin/77357c4135a111b203Ny2Ni7EQ~~/) 润宇官网全栈岗位要求后端语言之一与 Vue/React，并强调从需求到上线。[官网](https://www.runyuchina.com/about/jobs/) 这支持全栈交付能力的相关性，不证明所有公司都要求 Java+Agent+前端三项。

## 实施与简历
建议一个主项目做完整：Spring Boot + Vue/React 二选一 + 关系数据库；按业务需要增加缓存、异步任务与消息队列。Agent 框架按 Java 集成需要选择一种。先模块化单体，出现明确隔离或伸缩需求再拆服务。
交付源码、可复现部署、业务演示、架构与数据模型、评测报告。实测并记录问答引用正确率、工具任务成功率、P95 延迟、单次成本、权限与幂等测试结果；区分模拟数据和真实业务，不填写未经测量的效果数字。
